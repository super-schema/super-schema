# Story 6.3: Compliance Report Export

Status: review

## Story
As a **compliance officer**, I want to export compliance query results and gap analysis as auditable reports, so that I can provide evidence to auditors without manual data collection.

## Acceptance Criteria

**Given** compliance queries and gap detection work (Stories 6.1-6.2 complete)
**When** report export is implemented
**Then** the compliance dashboard has an **"Export"** button (secondary button in the top-right) that opens an export options popover
**And** the export popover offers format options: **CSV** (tabular data) and **PDF** (formatted report with headers and summary)
**And** **CSV export** includes all currently filtered/visible fields with columns: Entity, Field, Type, Classification, Retention, Anonymization, Encryption, Targets, Domain, Gap Type (if on Gaps tab) — respecting current filters and sort order
**And** **PDF export** generates a formatted report with: report title ("Super Schema Compliance Report"), generation date, applied filters summary, total counts, a table of all matching fields, gap analysis summary (if exported from Gaps tab), and a footer with "Generated by Super Schema — [date] — [user]"
**And** the export includes **all results** (not just the current page) — pagination is ignored for export
**And** the exported file name follows the pattern: `compliance-report-{date}-{filters}.{csv|pdf}` (e.g., `compliance-report-2026-04-02-pii.csv`)
**And** the export is triggered client-side (CSV via blob download, PDF via a library like jsPDF or server-generated) — no external service calls
**And** unit tests verify: CSV contains correct headers and data matching the filter, PDF generation produces a valid file, all results are included regardless of pagination
**And** a Playwright E2E test verifies: clicking Export → selecting CSV → file downloads with correct content, applying filters → export only includes filtered results

## Dev Notes

### Architecture & Patterns
- **Client-side generation**: Both CSV and PDF are generated in the browser. No server-side PDF rendering. This satisfies the "no external service calls" requirement.
- **Service layer reuse**: Export data comes from the same `queryFields()` and `detectGaps()` service functions, just with pagination removed.
- **Result type**: The export data endpoint returns `Result<ComplianceFieldResult[]>` (full dataset).
- **withAudit()**: Log export actions to audit trail with action `compliance.export` including format and filter summary.

### UX/Design Requirements
- **Export button**: Secondary button style (outlined, not filled) in the top-right corner of the compliance dashboard, consistent with Hex-inspired button patterns.
- **Popover**: Frosted glass popover with backdrop blur. Two rows: CSV icon + "CSV — Tabular data for spreadsheets", PDF icon + "PDF — Formatted report with summary".
- **Loading state**: Button shows spinner while export is processing.
- **Toast**: Success toast slides in from bottom-right on successful download.
- **File naming**: `compliance-report-2026-04-02-pii-sensitive.csv` — filter values joined by hyphens. If no filters, just `compliance-report-2026-04-02.csv`.

### File Structure
```
src/features/compliance/ComplianceExportPopover.tsx  # Export button + popover
src/features/compliance/exportCsv.ts                 # CSV generation utility
src/features/compliance/exportPdf.ts                 # PDF generation utility
src/server/api/routers/compliance.ts                 # Extended — exportData procedure
```

### Testing Requirements
- **Unit tests** (`tests/unit/features/compliance/export.test.ts`):
  - CSV generation includes correct headers
  - CSV data matches the provided filter results
  - CSV includes all results (not paginated subset)
  - PDF generation produces a valid PDF blob
  - PDF includes report title, date, filters summary, footer
  - File naming follows the correct pattern with date and filters
- **E2E tests** (`tests/e2e/compliance-export.spec.ts`):
  - Click Export button, popover opens with CSV and PDF options
  - Select CSV — file downloads (verify download event)
  - Apply filters, export — exported content only includes filtered results
  - Export from Gaps tab — CSV/PDF includes Gap Type column
